# AutoDrive Fly 行为稳定性优化复盘

## 当前 v4 结论

旧道路生成器把所有首障碍固定在左侧，系统性奖励右转；同时早撞首障碍会让
“未出界”看起来像稳定。v4 将相邻种子构造成严格左右镜像道路，使用独立的
`400–431` 测试段，并记录首障碍侧别、完整通过、提前碰撞和障碍通过数量。

原图与镜像图分别驱动同一个 166,700 节点连接组的两份持续状态，转向读取奇分量，
纵向前进与 MDN 后退读取偶分量。最终 16 对测试道路上原始/执行转向、横向轨迹、
里程和终止时间镜像误差为 0，固定右转偏置已消除。直行是基础纵向原语，DNp20
只提供转向残差，DNpe017 调速，4 个真实 MDN 提供条件后退。

候选仍未达到可用性：通关率 0%，平均通过 2.5/9 个障碍、行驶 41.55m，低于
零转向直行基线的 49.15m。安全层消融将出界率从 12.5% 降至 0%，但首障碍前
碰撞率仍为 18.75%，通关率仍为 0%；因此候选被保留但不发布。以下章节是历史
v2 问题和修复过程，数值不可直接用于 v4。

## 1. 用户观察与证据

用户观察到车辆容易直接转出道路，而且离障碍很远时仍持续左右晃动。量化后发现：

- 页面默认把在线学习和探索绑定，随机转向会放大摇摆；
- 即使关闭探索，旧部署策略仍存在稳定单向偏置；
- 车辆把神经转向直接累加到航向，没有死区、转角变化率和合理运动学；
- 奖励没有道路边界、航向和转向平滑成本；
- 障碍和道路边界共用同一最小射线，空道路也会被判为“危险”；
- v1 检查点只保存增益，没有运行均值/方差。旧重放测试复用了训练对象，
  所以旧 `+41.79m` 学习结论不能作为部署证据。

## 2. 已实施的优化

### 2.1 模式解耦

执行、在线可塑性和探索噪声成为三个独立开关。页面默认：

```text
在线可塑性 = 关闭
探索噪声   = 关闭
道路安全约束 = 开启
```

因此普通演示不会一边执行一边随机探索和改写突触。

### 2.2 车辆执行器

加入转向死区、每步转角变化率限制和简化自行车模型。神经输出成为目标方向盘
命令，不再直接作为无限累积的航向角速度。

### 2.3 感知拆分

环境分别输出 `obstacle_rays` 和 `wall_rays`。障碍教学只读障碍距离，道路约束
只读横向位置与航向，避免空路斜射线被当作障碍。

### 2.4 双层运动零点

慢速全局零点随校准暴露形成并保存到检查点；每回合还有基于双侧 DN 自身活动的
高通适应，用于滤除新场景的低频共同偏置。它不读取车辆横向位置或障碍几何。

### 2.5 有界可塑性

局部增益限制为解剖基线的 `0.97–1.03×`，并缓慢回归 1.0。训练更新还会补偿
当前活动模式下的零点变化，避免一次突触更新立即成为永久左/右偏置。

### 2.6 透明道路安全约束

安全层只在车辆接近道路外侧或航向继续向外时渐进介入。它：

- 不读取障碍；
- 不决定从障碍哪边绕行；
- 可以独立关闭；
- 同时展示原始神经转向、实际转向、混合强度和修正值。

因此它是明确标注的执行安全层，不会冒充果蝇学习能力。

## 3. 当前可靠结果

最终发布策略是 `frozen_calibrated`，不含学习后权重收益。对种子 200–231，
关闭学习和探索，唯一变量是道路安全约束：

| 指标 | 约束关闭 | 约束开启 |
|---|---:|---:|
| 平均距离 | 26.80 m | 30.33 m |
| 平均回报 | 4.38 | 5.21 |
| 侧边界退出率 | 25% | 0% |
| 最大横向偏移 | 3.08 m | 2.41 m |
| 障碍碰撞率 | 75% | 100% |
| 安全层介入率 | 0% | 26.2% |

距离增益 `+3.53m`，95% CI `[1.07, 6.47]`；回报增益 `+0.84`，95% CI
`[0.25, 1.53]`。平均转向和转向变化率也略有下降。
安全层平均动作修正量为 `0.032`，所以它是局部介入而非全程替代神经控制。

稳定化后的在线多巴胺塑性结果为负：距离 `−1.21m`，回报 `−0.29`。评估器
按门槛拒绝发布学习检查点。这一负结果说明当前有效收益来自行为约束，而不是已经
证明果蝇网络学会避障。

## 4. 检查点证据修复

v2 检查点保存：

- 四个运动目标 body ID；
- 每个可塑输入的 presynaptic body ID；
- 连接增益；
- 运行均值和方差；
- 奖励基线；
- 转向零点；
- 检查点类型。

候选学习策略必须先保存，再由全新 `DrivingEngine` 加载后评估。距离、回报、置信
区间、侧边界退出、远障碍转向和平滑度门槛全部通过才会覆盖正式检查点。

## 5. 尚未解决的问题

- 32 个未见场景通关率仍是 0%；
- 安全层把“出道路”转化成“撞障碍”，没有解决障碍规划；
- 油门通路基本没有学会接近障碍时主动减速；
- 当前 DN 输入可塑性没有稳定正收益；
- 训练期 clearance 仍属于特权奖励塑形；
- 尚未完成 KC→MBON 可塑性、视网膜打乱、目标打乱图和参数匹配 MLP 对照。

## 6. 下一轮优先级

1. 分离障碍方位与道路边缘表征，增加左右镜像等变测试；
2. 让 DNpe017 油门通路参与危险接近学习；
3. 实现 KC→MBON11→运动读出的局部记忆路径；
4. 以安全层关闭和开启两种模式分别报告神经能力与产品安全性；
5. 加入曲线路界、不同障碍密度和传感噪声的跨分布测试。

## 7. 结论

用户关于“行为约束”的判断得到支持：显式约束是当前消除侧向出界的主要收益来源。
项目已经不再把这部分收益归因于多巴胺学习。当前版本解决的是控制稳定性和证据
完整性，障碍规避学习仍是下一阶段任务。
